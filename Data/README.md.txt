# Dataset

## Data Period

This project uses 12 months of Cyclistic bike-share trip data covering:

**September 2025 – August 2026**

## Data Source

The trip data was provided as monthly datasets for the bike-share service.

The original monthly datasets were combined using **Excel Power Query** into a single full-year dataset.

## Data Preparation

The datasets were:

- Combined using Power Query
- Checked for consistency
- Cleaned and prepared for analysis
- Converted ride duration into minutes
- Used to create day-of-week fields
- Loaded into the Excel Data Model for analysis

## Dataset Size

The combined dataset contains approximately **6.1 million rides**.

Because the dataset is larger than Excel's worksheet row limit, the full dataset was analyzed using the **Excel Data Model and PivotTables**.

## Original Data Files

The 12 original monthly files are not included in this GitHub repository because of their large file size.

The repository contains the analysis workbook, documentation, dashboard screenshot, and methodology instead.
